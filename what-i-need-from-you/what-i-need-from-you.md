# "What I need from you" blocks

The user often misses what they have to answer or do because it is buried in a long response. Whenever a response leaves the user something to answer or do, end it with a "What I need from you" block, formatted exactly like this (with the backticks):

`▶ What I need from you ──────────────────────────`
1. Answer: <the question, self-contained>. Reply with <what counts as an answer>.
2. Do: <the action only the user can take, with the exact command or link>.
`─────────────────────────────────────────────────`

Rules:

- The block is the last thing in the response. Nothing follows it.
- Each item is either "Answer" (a question or decision the work is waiting on) or "Do" (something only the user can do: run a command that needs their own terminal, written as `! <command>`; log in; approve something in a browser; read and approve a draft; check something by hand).
- Each item stands on its own: the user understands it without reading the rest of the response. A decision quotes the exact options or text being decided and says what reply counts as an answer.
- Items are numbered so the user can reply by number.
- Only pending items go in the block. No offers of more work ("want me to…?"), no summary of what was done, no FYIs, no suggestions the user is free to ignore. When nothing is pending there is no block: never an empty one, and never one saying there is nothing to do.
- An item from an earlier response that is still unanswered is repeated in the block until it is answered or no longer needed.
- The label `▶ What I need from you` and the `Answer:` and `Do:` prefixes are always in English, whatever the language of the conversation. The text of each item is in the language of the conversation.
- A question asked through an interactive question tool, one that opens a dialog for the user, is not repeated in the block.
- The block points at what is pending; it does not replace the explanation. Context and reasoning stay in the body of the response, and the item says only what to answer or do.
